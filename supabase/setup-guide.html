📖 Panduan Setup Backend (Supabase)

Status AKTIF/NONAKTIF absensi berasal dari server, bukan localStorage browser. Ikuti langkah berikut.

1. Buat Project Supabase (Gratis)

  1. Buka https://supabase.com lalu sign up / login.
  2. Klik New project dan isi nama, password database, region terdekat.
  3. Tunggu project selesai dibuat (1-2 menit).

2. Jalankan SQL Setup

  1. Di dashboard Supabase, buka SQL Editor.
  2. Buka file supabase/setup.sql di repo ini.
  3. Copy seluruh isinya, paste ke SQL Editor, klik Run.
  4. Pastikan tidak ada error. Ini akan membuat:
    • Tabel sessions (1 baris, id=1) + fungsi get_session_status()
    • Tabel students (dengan kolom aktif) dan check_ins (+ index harian)
    • Fungsi find_students(), get_student_public(), submit_checkin(), get_server_date(), get_selfie_url()
    • Bucket Storage selfies (privat; anon hanya boleh upload)
Fungsi get_session_status() dan submit_checkin() memakai jam server PostgreSQL sebagai sumber waktu utama. Device siswa tidak dipercaya untuk waktu.

2b. Isi Data Siswa (tanpa NIS)

Aplikasi tidak memakai NIS. Isi nama & kelas tiap siswa:

  1. Buka Table Editor → students → Insert row.
  2. Isi nama dan kelas. Kolom nis wajib diisi nilai unik apa saja (mis. S001) karena warisan skema lama — tidak dipakai aplikasi.
  3. Biarkan aktif = true. Set false untuk menonaktifkan siswa (tidak muncul di pencarian, tidak bisa check-in).
NIS tidak pernah ditampilkan atau diminta ke siswa.

3. Aktifkan RLS / Kebijakan Akses

Di Authentication → Policies untuk tabel sessions, students, check_ins:

  • Untuk mempermudah tahap awal, aktifkan RLS lalu tambahkan policy read untuk semua orang (anon) di sessions.
  • Untuk students & check_ins, gunakan fungsi security definer (find_students, get_student_public, submit_checkin) yang sudah membatasi kolom (tanpa NIS).
  • Jangan buat policy baca publik pada bucket selfies. Selfie hanya dibuka admin via get_selfie_url() (tautan sementara 60 detik).
Jangan simpan service_role key di frontend. Hanya gunakan anon/public key di supabase-config.js.

4. Isi Konfigurasi Frontend

  1. Di Supabase dashboard, buka Settings → API.
  2. Copy Project URL dan anon public key.
  3. Buka file assets/js/supabase-config.js dan ganti nilainya:
window.SUPABASE_CONFIG = {
  url: 'https://abcdefgh.supabase.co',
  anonKey: 'eyJhbGciOi...'
};

5. Test Halaman /checkin

  1. Buka checkin/index.html di browser (atau deploy ke GitHub Pages).
  2. Halaman otomatis memanggil get_session_status().
  3. Jika backend terhubung: muncul status AKTIF / NONAKTIF sesuai server.
  4. Jika AKTIF → Lanjutkan Absensi → cari namamu di kotak pencarian → pilih dari daftar → kelas terisi otomatis → ambil selfie → simpan.
  5. Jika backend belum dikonfigurasi: muncul pesan jelas, bukan crash.

6. URL QR Permanen

Cetak QR yang mengarah ke satu URL permanen, misalnya:

https://username.github.io/Siswa-Berangkat-Pagi/checkin/

QR tidak perlu diganti tiap hari. Status dicek dari server setiap scan.

➤ Buka halaman /checkin 📖 Dashboard Admin ← Kembali ke Portal

7. Dashboard Admin

  1. Buka checkin/dashboard.html (atau via tautan di atas).
  2. Di sana admin dapat:
    • Aktifkan / nonaktifkan sesi secara manual (override)
    • Atur jam mulai & selesai jadwal otomatis
    • Melihat siswa paling pagi hari ini
    • Melihat daftar check-in hari ini (nama, kelas, waktu)
    • Membuka selfie via tombol Lihat Selfie (tautan sementara 60 detik)
  3. Status ditampilkan persis dari server via get_session_status().
Dashboard saat ini tanpa login. Siapa pun yang tahu URL-nya bisa melihat data & selfie. Tambahkan proteksi (Supabase Auth / PIN) bila akan dipakai produksi.
